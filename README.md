# 3D model viewer

Browser-based viewer for OBJ (+MTL + textures) models exported from Archicad. Everything runs locally in your browser — your models are never uploaded anywhere.

- Open the viewer, then **open export folder** (or drag a folder in) to view your own model.
- **load sample model** loads the bundled `sample_project`.
- Direct link that opens the sample model: add `?model=sample_project` to the page address.

Böngészős OBJ (+MTL + textúra) néző Archicad exportokhoz. Minden a saját böngésződben fut, a modelleid nem kerülnek fel sehova.
